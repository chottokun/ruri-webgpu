# ruri-webgpu Chrome 拡張機能

ruri-webgpu を使用した Chrome 拡張機能（Manifest V3）です。WebGPU を用いて、ブラウザ上で完全なローカルセマンティック検索（意味検索）を実現します。

## 機能

- 現在開いている Web ページのコンテンツを抽出してインデックス化
- `Chottokun/ruri-v3-30m-lite` と ONNX Runtime Web を使用し、ローカルで文章の埋め込み（Embedding）を計算
- IndexedDB を使用してローカルにデータを永続化
- **ハイブリッド検索 (`local-ai-grep` 仕様)**: ベクトルのコサイン類似度（セマンティック検索）に加え、タイトルまたは本文にキーワードが一致した場合にスコアを加算（+0.25 ブースト）し、短い単語や固有名詞・コード名の取りこぼしを防止
- サイドパネルから直感的に「意味」で検索が可能（ハイブリッド検索の ON/OFF トグル付き）

## ビルド方法

拡張機能をビルドするには、以下のコマンドを実行します。

```bash
npm install
npm run build:extension
```

ビルドが成功すると、`dist-extension/` ディレクトリに拡張機能のファイルが生成されます。

## Chrome へのインストール方法

1. Chrome ブラウザを開き、アドレスバーに `chrome://extensions/` と入力して拡張機能管理ページを開きます。
2. 画面右上の「デベロッパー モード」をオンにします。
3. 画面左上の「パッケージ化されていない拡張機能を読み込む」ボタンをクリックします。
4. このプロジェクトの `dist-extension/` フォルダを選択して開きます。
5. 「ruri-webgpu 意味検索」が拡張機能一覧に追加されれば準備完了です。

## 使用方法

1. 拡張機能のアイコンをクリックしてサイドパネルを開きます（またはサイドパネルから直接開きます）。
2. 初回起動時はモデルのダウンロードと初期化が行われます。
3. インデックスしたい Web ページを開いた状態で、「現在のページをインデックス」ボタンをクリックします。
4. サイドパネルの検索ボックスに検索クエリ（例: 「AIについて」）を入力すると、類似度順にインデックスされたページが表示されます。
5. 検索結果をクリックすると、該当のページを新しいタブで開きます。

## セキュリティに関する注意事項

Manifest V3 の Content Security Policy (CSP) 制限により、外部の CDN スクリプトや WASM ファイルを直接読み込むことはできません。
そのため、ビルド時に ONNX Runtime Web の必要なファイル (`ort.all.min.js`, `*.wasm`) を拡張機能内の `assets/ort/` ディレクトリにコピーし、ローカルから読み込むように構成されています。
