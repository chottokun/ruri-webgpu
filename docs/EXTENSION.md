# ruri-webgpu Chrome 拡張機能 (AI ページ内検索)

ruri-webgpu を使用した Chrome 拡張機能（Manifest V3）です。WebGPU を用いて、ブラウザ上で完全なローカルセマンティック検索（意味検索）を実現します。

## 機能概要

**「閲覧中の Web ページ内を、Ctrl+F のようにセマンティック（意味）＆ハイブリッドでリアルタイムにストリーム検索＆インラインハイライト」** する拡張機能です。過去ページの全体インデックスや保存は不要で、閲覧中のページで即座に動作します。

- **画面右上にフロート表示されるスマート検索バー (`Ctrl+F` / `Ctrl+Shift+F`)**: ブラウザ標準の Ctrl+F と同じ感覚で使えるコンパクトで洗練された検索バー。
- **ページ内ストリーム意味解析 & ハイライト**: ページ内の文・段落をリアルタイムに文分割し、クエリとのコサイン類似度上位の文章をリアルタイム特定。
- **全マッチ常時ハイライト & カレント強調ジャンプ**: 該当するすべての文章が黄色で常時ハイライトされ、現在選択中の文（紫色）へ自動スムーズスクロール。
- **ハイブリッド検索 (`--hybrid` 準拠)**: ベクトルのコサイン類似度（セマンティック検索）に加え、キーワード一致時にスコアを加算（+0.25 ブースト）し、固有名詞やコード名の取りこぼしを完全に防止。
- **オンメモリキャッシュ**: 一度計算されたページ内の文ベクトルはオンメモリに保持され、検索キーワードを変更した際も超高速に即時再ランキング。
- **完全 CSP (Manifest V3) 準拠**: JSEP モジュールの静的インライン化と Pure JS トークナイザーにより、動的 import や `unsafe-eval` の制限を完全に回避。

## Chrome へのインストール方法

1. Chrome ブラウザを開き、アドレスバーに `chrome://extensions/` と入力して拡張機能管理ページを開きます。
2. 画面右上の「デベロッパー モード」をオンにします。
3. 画面左上の「パッケージ化されていない拡張機能を読み込む」ボタンをクリックします。
4. この `dist-extension/` フォルダを選択して開きます。
5. 「ruri-webgpu 意味検索」が拡張機能一覧に追加されれば準備完了です。

---

## 使用方法

1. 任意の Web ページを開きます（拡張機能更新後は一度ページを F5 で再読み込みしてください）。
2. 以下のいずれかの方法で検索バーを開きます：
   - **`Ctrl+F`** (Mac: `Cmd+F`)
   - **`Ctrl+Shift+F`** (Mac: `Cmd+Shift+F` - Chrome公式ショートカット)
   - **`Ctrl+K`** (Mac: `Cmd+K`)
   - ブラウザ右上の **拡張機能アイコンをクリック**
3. 検索バーに探したい内容（文章、キーワード、文脈）を入力します。
4. **ナビゲーション & 表示操作**:
   - **`Enter`** または **`▼` ボタン**: 次の一致箇所へ移動 & 強調表示
   - **`Shift+Enter`** または **`▲` ボタン**: 前の一致箇所へ移動 & 強調表示
   - **`Alt+H`** または **🖊️ (ハイライター) ボタン**: テキスト上の黄色ハイライト表示のオン/オフ切り替え（設定は記憶されます）
   - **ドロップダウンカードのクリック**: 該当箇所へ直接ジャンプ
   - **`Esc`** または **`✕` ボタン**: 検索バーを閉じる（ハイライトも自動消去）

## トラブルシューティング

- **通常の検索窓が出てしまう場合**:
  - ページを開いた後に拡張機能を更新した場合は、ページ側を `F5`（更新）してください。
  - ブラウザのキー割り当てにより `Ctrl+F` が横取りされる場合は、**`Ctrl+Shift+F`** または **拡張機能アイコンクリック** で確実に起動できます。
- **WebGPU の利用について**:
  - WebGPU が利用可能な環境では自動的に WebGPU (FP16) で超高速に推論が実行されます。非対応環境でも WASM (CPU) に安全にフォールバックします。
