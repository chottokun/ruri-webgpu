# ruri-webgpu Chrome 拡張機能 (Manifest V3)

本リポジトリで提供している ruri-webgpu を利用した Chrome 拡張機能（Manifest V3）の技術文書です。WebGPU とローカルモデルを用いて、閲覧中の Web ページ内でセマンティック検索を行います。

## 機能概要

Webページ内を対象としたインライン意味検索機能です。閲覧中のページ内で動作し、事前のインデックス作成や外部サーバーへのデータ送信は行いません。

- **検索バー (`Ctrl+F` / `Cmd+F`)**: ブラウザの標準検索のキー入力をインターセプトして検索インターフェースを表示します（競合時は `Ctrl+Shift+F` または `Ctrl+K` でも起動可能）。
- **ページ内ストリーム意味解析 & ハイライト**: ページ内の文・段落を抽出し、クエリとのコサイン類似度に基づきリアルタイムに文ベクトルを評価します。
- **ハイライト表示とナビゲーション**: 類似度の上位に該当する文章をハイライトし、現在選択中の箇所へスクロールします。
- **ハイブリッド検索 (`--hybrid` 準拠)**: ベクトルのコサイン類似度に加え、キーワードの完全一致時にスコアを加算（+0.25 ブースト）し、固有名詞などの検索漏れを軽減します。
- **オンメモリキャッシュ**: ページ内で計算された文ベクトルはオンメモリに保持され、検索キーワード変更時の再ランキング処理時間を短縮します。
- **CSP (Manifest V3) 準拠**: JSEP モジュールの静的インライン化と Pure JS トークナイザーの使用により、動的 import や `unsafe-eval` 制約に対応しています。

---

## インストール手順

1. Chrome ブラウザで `chrome://extensions/` を開きます。
2. 画面右上の「デベロッパー モード」を有効にします。
3. 画面左上の「パッケージ化されていない拡張機能を読み込む」ボタンをクリックします。
4. 本リポジトリ内でビルドした `dist-extension/` フォルダを選択します。

---

## 使用方法

1. 任意の Web ページを開きます（拡張機能のインストール・更新直後はページの再読み込みが必要です）。
2. 以下のいずれかの方法で検索バーを起動します：
   - **メイン起動**: **`Ctrl+F`** / **`Cmd+F`** (ページ内検索をインターセプト)
   - **Chrome公式 / 競合回避起動**: **`Ctrl+Shift+F`** / **`Cmd+Shift+F`**
   - **代替起動**: **`Ctrl+K`** / **`Cmd+K`**
   - 拡張機能アイコンをクリック
3. 検索バーに検索クエリを入力します。
4. **ナビゲーション & 表示操作**:
   - **`Enter`** または **`Shift+Enter`**: 次 / 前の一致箇所へ移動
   - **`Alt+H`**: ハイライト表示のオン/オフ切替
   - **`Esc`**: 検索バーを閉じる

## 技術アーキテクチャ・設計解説

本拡張機能は、Chrome Manifest V3 の Content Security Policy (CSP) 制約内で WebGPU とローカルモデルを動作させるため、以下の設計を採用しています。

- **Offscreen API による推論処理**:
  Service Worker からは WebGPU や DOM へのアクセスが制限されているため、`DOM_PARSER` を理由とした Offscreen Document を生成し、そこで ONNX Runtime Web を実行しています。これにより推論処理を分離しています。
- **Pure JS SentencePiece トークナイザー**:
  WASM ベースのトークナイザーは `unsafe-eval` 制約に抵触する可能性があるため、`@huggingface/tokenizers` を使用して `tokenizer.json` を純粋な JavaScript としてパースしています。
- **ハイブリッド検索（コサイン類似度 + キーワードブースト）**:
  ベクトル検索では未知の固有名詞や英単語の識別が困難な場合があるため、コサイン類似度の計算結果に対して、クエリのキーワード完全一致時にスコアを加算する仕組み（+0.25 ブースト）を導入しています。

## トラブルシューティング

- **ブラウザ標準の検索バーが表示される場合**:
  - ページを開いた後に拡張機能を更新した場合は、ページを再読み込みしてください。
  - ページや他の拡張機能により `Ctrl+F` がインターセプトされる場合は、`Ctrl+Shift+F` または拡張機能アイコンクリックを使用してください。
- **WebGPU のフォールバック**:
  - WebGPU が利用可能な環境では自動的に WebGPU (FP16) を使用します。非対応環境では WASM (CPU) にフォールバックします。
