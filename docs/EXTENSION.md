# ruri-webgpu Chrome 拡張機能

ruri-webgpu を使用した Chrome 拡張機能（Manifest V3）です。WebGPU を用いて、ブラウザ上で完全なローカルセマンティック検索（意味検索）を実現します。

## 機能

- **インライン検索オーバーレイUI (`Cmd+K` / `Ctrl+K`)**: 閲覧中の任意のWebページ上に直接 Glassmorphism デザインの検索バー・モーダルを表示。サイドパネルを開くことなく即座に意味検索が可能
- **ページ内ストリーム解析 & ハイライト**: 閲覧中ページの文章をリアルタイムに文分割・ベクトル化し、クエリとのコサイン類似度上位の文章へワンクリックでスムーススクロール＆アニメーションハイライト
- 現在開いている Web ページのコンテンツを抽出してインデックス化（全体検索モード）
- `Chottokun/ruri-v3-30m-lite` と ONNX Runtime Web を使用し、ローカルで文章の埋め込み（Embedding）を計算
- IndexedDB を使用してローカルにデータを永続化
- **ハイブリッド検索 (`local-ai-grep` 仕様)**: ベクトルのコサイン類似度（セマンティック検索）に加え、タイトルまたは本文にキーワードが一致した場合にスコアを加算（+0.25 ブースト）し、短い単語や固有名詞・コード名の取りこぼしを防止
- **完全 CSP (Manifest V3) 準拠**: `@huggingface/tokenizers` を採用し、`unsafe-eval` を一切排除

## ビルド方法

拡張機能をビルドするには、以下のコマンドを実行します。

```bash
npm install
npm run build:extension
```

ビルドが成功すると、`dist-extension/` ディレクトリに拡張機能のファイルが生成されます。

## Chrome へのインストール方法

1. Chrome ブラウザを開き、アドレスバーに `chrome://extensions/` と入力して拡張機能管理ページを開きます。
2. 画面右上の「デベロッパー モード」をオンにします。
3. 画面左上の「パッケージ化されていない拡張機能を読み込む」ボタンをクリックします。
4. このプロジェクトの `dist-extension/` フォルダを選択して開きます。
5. 「ruri-webgpu 意味検索」が拡張機能一覧に追加されれば準備完了です。

## 使用方法

1. 任意のWebページを開き、キーボードショートカット `Cmd+K` (Mac) または `Ctrl+K` (Windows/Linux) を押すか、拡張機能アイコンをクリックしてインライン検索オーバーレイを起動します。
2. **全体モード**:
   - 「現在のページをインデックス」ボタンを押すと、閲覧中ページの内容が IndexedDB に登録・ベクトル化されます。
   - 検索ボックスにクエリを入力すると、過去に保存したページ群から意味が近いページがスコア順に表示され、クリックで該当URLに遷移できます。
3. **ページ内モード**:
   - 「ページ内」タブを選択し、「ページ内の文を解析」をクリックします。
   - ページ内の文章がストリーミング解析され、検索クエリに最も関連する文章がランキング表示されます。
   - 結果をクリックすると、該当の段落・文へ自動スクロールし、ハイライト表示されます。

## セキュリティに関する注意事項

Manifest V3 の Content Security Policy (CSP) 制限により、外部の CDN スクリプトや WASM ファイルを直接読み込むこと、および `unsafe-eval`（`eval` や `new Function`）の使用は禁止されています。
- ONNX Runtime Web の必要なバイナリ (`ort.all.min.js`, `*.wasm`) は拡張機能内の `assets/ort/` ディレクトリに完全ローカル同梱されています。
- トークナイザーには純粋な JS / CSP 適合の `@huggingface/tokenizers` を使用し、`unsafe-eval` 違反を完全に排除しています。
