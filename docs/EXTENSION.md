# ruri-webgpu Chrome 拡張機能

ruri-webgpu を使用した Chrome 拡張機能（Manifest V3）です。WebGPU を用いて、ブラウザ上で完全なローカルセマンティック検索（意味検索）を実現します。

## 機能概要

**「閲覧中の Web ページ内を、Cmd+F (Ctrl+F) のように意味（セマンティック）でリアルタイムにストリーム検索＆インラインマーキング」** する拡張機能です。過去ページの全体インデックスや保存は不要で、閲覧中のページで即座に動作します。

- **インライン検索オーバーレイUI (`Cmd+K` / `Ctrl+K`)**: 閲覧中の任意のWebページ上に直接 Glassmorphism デザインの検索バー・モーダルを表示。
- **ページ内ストリーム解析 & ハイライト**: ページ内の文・段落をリアルタイムに文分割し、クエリとのコサイン類似度上位の文章へワンクリック（または Enter キー）でスムーススクロール＆インラインハイライト。
- **ハイブリッド検索 (`--hybrid` 準拠)**: ベクトルのコサイン類似度（セマンティック検索）に加え、キーワード一致時にスコアを加算（+0.25 ブースト）し、固有名詞やコード名の取りこぼしを完全に防止。
- **オンメモリキャッシュ**: 一度計算されたページ内の文ベクトルはオンメモリに保持され、検索キーワードを変更した際も超高速に即時再ランキング。
- **完全 CSP (Manifest V3) 準拠**: JSEP モジュールの静的インライン化と、Pure JS のトークナイザーを採用し、動的 import や `unsafe-eval` の制限を完全に回避。

## ビルド方法

拡張機能をビルドするには、以下のコマンドを実行します。

```bash
npm install
npm run build:extension
```

ビルドが成功すると、`dist-extension/` ディレクトリに拡張機能のファイルが生成されます。

## Chrome へのインストール方法

1. Chrome ブラウザを開き、アドレスバーに `chrome://extensions/` と入力して拡張機能管理ページを開きます。
2. 画面右上の「デベロッパー モード」をオンにします。
3. 画面左上の「パッケージ化されていない拡張機能を読み込む」ボタンをクリックします。
4. このプロジェクトの `dist-extension/` フォルダを選択して開きます。
5. 「ruri-webgpu 意味検索」が拡張機能一覧に追加されれば準備完了です。

## 使用方法

1. 任意のWebページを開き、キーボードショートカット `Cmd+K` (Mac) または `Ctrl+K` (Windows/Linux) を押すか、拡張機能アイコンをクリックしてインライン検索オーバーレイを起動します。
2. 検索バーに探したい内容（文章、キーワード、文脈）を入力します。
3. 入力したクエリに対して、ページ内の文章がストリーミングで意味解析され、スコア順（ハイブリッド）にリアルタイムランキング表示されます。
4. `↑` / `↓` キーまたはマウスで候補を選択し、`Enter` キーを押すかカードをクリックすると、ページ内の該当文章へスムーズスクロールし、インラインハイライト（フェードアウトアニメーション）でマーキングされます。
5. `Esc` キーまたは ✕ ボタンでオーバーレイを閉じます。
